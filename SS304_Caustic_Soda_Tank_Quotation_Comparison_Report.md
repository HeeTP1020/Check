### 3.2 Critical API 650 Non-Conformances Identified

**NON-CONFORMANCE 1 — Shell Weld NDT (Falkor)**
> API 650 Section 8.1 requires radiographic testing (RT) of all vertical shell joints and a percentage of horizontal shell joints. For tanks over a certain size, RT or UT is mandatory. Penetrant Testing (PT) alone is a surface-only method and cannot detect subsurface weld defects. PT is supplementary, not a substitute, for RT or UT per API 650.
> **Status: CRITICAL — FES must confirm RT or UT will be performed on shell vertical joints.**

**NON-CONFORMANCE 2 — Missing API 650 Design Data (All Vendors)**
> No vendor has provided design pressure, design temperature, corrosion allowance, or design wind/seismic basis. This data is required for the API 650 design to be meaningful and verifiable.

**NON-CONFORMANCE 3 — 304 vs. 304L Material (Credo)**
> Credo specifies "SS304" without confirming 304L grade. For welded stainless steel tanks in caustic soda service, SS304L is strongly preferred to prevent sensitization (chromium carbide precipitation at grain boundaries) in the heat-affected zone, which can lead to intergranular corrosion in the caustic environment.

**NON-CONFORMANCE 4 — Missing Vacuum Box Test (All Vendors)**
> API 650 Section 8.6 requires vacuum box testing of all horizontal bottom plate joints. No vendor mentions this test. This is a mandatory API 650 inspection requirement.

**NON-CONFORMANCE 5 — No WPS/PQR or Welder Qualification (All Vendors)**
> API 650 Section 7 requires all welding to be performed to qualified procedures (WPS/PQR per ASME Section IX or API standard) with qualified welders. No vendor references these documents.

**NON-CONFORMANCE 6 — Tank Dimensions Inconsistency (Credo vs. Synergex)**
> Credo proposes 10m D × 20.5m H. Synergex proposes 10m D × 23m H (overall). For 1,600 m³ at 10m diameter, the required shell height is approximately 20.4m. A 23m overall height implies either excessive freeboard, an unusually tall roof cone/dome, or the volume calculation is incorrect. This must be clarified as it affects tank cost and structural design significantly.

**Engineering Assessment of Pile Count:**

For a 1,600 m³ SS304L tank at the FES-stated 11,450 mm ID and 15,400 mm height:
- Tank empty weight (shell + roof + bottom + nozzles + accessories): approximately 85–90 tonnes = ~850–900 kN
- Operating fluid weight (NaOH, SG ~1.36): 1,600 m³ × 1,360 kg/m³ = 2,176 tonnes = 21,300 kN
- Hydrotest weight (water, SG 1.0): 1,600 m³ × 1,000 = 1,600 tonnes = 15,700 kN
- Total foundation load at hydrotest: ~16,600 kN distributed over ~103 m² base
- Geometry check: 11.45m ID × 15.4m straight height gives ~1,586 m³ gross cylinder volume before freeboard, so FES must confirm the final shell height/roof geometry and usable capacity

For Jurong Island reclaimed land (typically marine clay with poor bearing capacity), the foundation design must account for:
- Weak, compressible marine clay stratum (can extend 20–40m depth)
- High risk of differential settlement
- Long-term consolidation settlement

**20 piles (FES)** at unknown specifications for this load is a major concern. Typical micropiles in Singapore reclaimed land at 33m depth carry approximately 300–800 kN each. Even at 800 kN, 20 piles provides only 16,000 kN total capacity — barely adequate for one tank's hydrotest load with no safety factor. This is a **critical issue that must be resolved before PO award.**

**74 micropiles at 33m (Credo)** is more consistent with industry practice for this site condition.

**125 jack-in piles at 12m (Synergex)** uses more piles but at shallower depth, which may be insufficient to reach competent bearing stratum at this site.

**Recommendation:** Request geotechnical report from client and verify all three pile designs against actual soil data.
