## Executive Summary

The original quotation comparison report (v2, 8 June 2026) provides a useful commercial overview but fails to address critical regulatory, process safety, geotechnical, and contractual requirements mandatory for Singapore. It recommends award to Falkor (FES) based on price and schedule, subject to seven clarifications. **However, the report is not sufficient for procurement approval** due to:

- **No formal Design Basis** (operating conditions, corrosion allowance, seismic/wind loads, nozzle schedule).
- **Complete omission of Singapore authority submissions** (SCDF, NEA, JTC, PUB, MOM, BCA, LTA, NParks).
- **No process safety analysis** (API 2350 overfill protection, HAZOP, bund volume calculation, emergency venting).
- **Missing geotechnical investigation** – foundation design (20 vs 74 vs 125 piles) is guesswork.
- **Critical technical gaps** (Falkor’s NDT – PT only – non-compliant with API 650).
- **Commercial gaps** (no liquidated damages, warranty, performance testing, insurance requirements).

**Verdict:** The report is **insufficient and potentially misleading** for procurement. Do not issue a Purchase Order based on it.

## 2. Engineering Compliance Gap Analysis

The original report highlights several API 650 gaps but misses many civil, piping, and E&I items.

### 2.1 Civil / Geotechnical

| Missing Item | Why Critical |
|---|---|
| Site-specific geotechnical investigation (boreholes, SPT, marine clay assessment) | Without soil data, pile design (20 vs 74 piles) is guesswork – differential settlement risk |
| Settlement monitoring plan (pre, during, post hydrotest) | Required by API 650 for large tanks on poor ground |
| Concrete durability specification (chemical-resistant coating for bund) | NaOH attacks concrete – spalling, leakage |
| Ringwall vs piled slab design | Not specified; impacts cost and safety |

| Missing Item | Standard |

| Wind girder intermediate design | API 650 §5.9 |

| Corrosion allowance for NaOH in SS304L | Must be stated (typically 0 mm but justify) |
| Roof live load (maintenance) | API 650 §3.10 |

### 2.3 Piping & E&I

- Pipe stress analysis (thermal expansion of 3” Sch-80 SS304L line) – **missing**
- Pipe support design – **missing**
- Valve schedule (isolation, emergency shutdown) – **missing**
- Lightning protection integration (SS IEC 62305) – FES excludes; others included but no standard.
- Instrumentation: level transmitter, high-high level alarm (API 2350) – **not mentioned**
- Leak detection – **not mentioned**

## 3. Process Safety Gap Analysis

The original report contains **no process safety evaluation**. For 1,600 m³ of caustic soda, the following are mandatory:

| Requirement | Status |
|---|---|
| API 2350 overfill prevention (independent high-high level switch & shutdown) | Not addressed |
| Secondary containment bund volume ≥ 110% of largest tank (with freeboard) | Not calculated – only height given (2.1m) |
| Emergency vent sizing (API 2000) for fire exposure | Not mentioned |
| HAZID / HAZOP study | Not mentioned |
| Pre-Startup Safety Review (PSSR) for MHI sites | Not mentioned |
| Bund lining (acid-resistant brick or coating) | Not specified |

> **Risk:** A caustic soda spill due to overfill or bund failure would cause severe environmental damage, injury, and legal liability.

## 4. Commercial & Contractual Gap Analysis

The original report notes some issues (e.g., Credo no LD) but fails to define required contractual protections.

| Missing Protection | Why Required |
|---|---|
| Performance guarantees (capacity, leak-tightness, passivation quality) | Ensures tank meets specification |
| Mechanical completion criteria | Clear milestone for testing |
| Defects liability period (minimum 12 months) | Vendor responsible for early failures |
| Liquidated damages for schedule delay | Enforces timeline |
| Insurance requirements (CAR – full replacement, PL S$5M, PI for PE) | Protects client from loss |
| Warranty (materials, workmanship) | Standard protection |
| Third-party inspection (TPI) – API 653 inspector | Independent quality assurance |
| Spare parts list (gaskets, fasteners) | Operational readiness |

**Recommendation:** Do **not** issue a PO using the original quotation language. A formal EPCC contract with the above clauses is required.

## 8. Additional Clarifications Required Before PO Award

The original report lists 7 clarifications for Falkor. The **client must also obtain/confirm**:

1. **Has SCDF Hazardous Materials Permit been applied for?** – If not, apply immediately.
2. **Provide a full geotechnical report** for 91 Sakra Avenue.
3. **Issue a formal Design Basis Memorandum** covering:
   - NaOH concentration, SG, temperature range
   - Design pressure / vacuum
   - Corrosion allowance (justify 0 mm or other)
   - Design life (e.g., 20 years)
   - Wind speed (SS EN 1991-1-4: Singapore 3-sec gust ~38 m/s)
   - Seismic zone (2 per SS EN 1998)
   - Nozzle schedule (sizes, ratings, orientations)
   - Freeboard requirement (>150 mm)
4. **Confirm if the site is a Major Hazard Installation (MHI)** – affects PSSR and safety case requirements.
5. **Budget and appoint a third-party API 653 inspector** (cost ~SGD 25,000–40,000).
6. **Request all vendors to quote for full API 650 compliance** including RT/UT NDT, vacuum box test, WPS/PQR, MTRs, and 12-month warranty.
7. **Draft a formal EPCC contract** with LD, warranty, insurance, and performance testing clauses.

## 9. Final Opinion: Is the Original Report Sufficient for Procurement Approval?

**NO. The report is NOT sufficient for procurement approval.**

**Reasons:**

- **Regulatory omissions** – fails to identify any of the eight required permits.
- **No design basis** – technical evaluation is meaningless without shared assumptions.
- **Critical technical gaps remain** (e.g., FES NDT non-compliant, pile count unsubstantiated) yet report still recommends award.
- **No process safety** – API 2350, HAZOP, bund sizing, emergency vent – all missing.
- **Commercial terms incomplete** – no warranty, LD, performance guarantees, insurance.

**Recommendation:**

> **Reject the original report as a basis for award. Pause procurement. First, secure permits, develop a Design Basis Memorandum, obtain geotechnical data, and draft a proper EPCC contract. Then seek revised quotations or re-tender.**
